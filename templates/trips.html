Import Trip Records (CSV)
  1. Download the CSV template and fill one trip of the Monthly Report of Official Travel per row (keep the header row): plate_number, trip_date, distance_km, actual_fuel_consumption (fuel consumed in liters), and optional remarks.
  2. Use the vehicle's plate number exactly as registered in Vehicles.
  3. Dates as YYYY-MM-DD, MM/DD/YYYY or 01-Sep-2026.
  4. In Excel save with File > Save As > CSV UTF-8 (plain CSV (Comma delimited) also works).
Every row is checked first; if any row has a problem nothing is imported and the rows to fix are listed. Trips that are already recorded (same vehicle, date, distance and fuel consumed) are skipped, so importing the same file twice is safe.
