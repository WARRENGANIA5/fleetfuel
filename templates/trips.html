Import Trip Records (CSV)
  1. Download the Excel template (with dropdowns and instructions) or the CSV template, and fill one trip ticket per row (keep the header row). Save the Excel file as CSV UTF-8 before importing.
  2. Use the vehicle's plate number exactly as registered in Vehicles.
  3. Dates as YYYY-MM-DD, MM/DD/YYYY or 01-Sep-2026; times as 08:30 or 8:30 AM.
  4. In Excel save with File > Save As > CSV UTF-8 (plain CSV (Comma delimited) also works).
Every row is checked first; if any row has a problem nothing is imported and the rows to fix are listed. Trips that are already recorded (same vehicle, date, time, odometer and distance) are skipped, so importing the same file twice is safe.
