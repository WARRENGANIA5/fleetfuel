TRAIN THE MODEL IN GOOGLE COLAB

Files in this folder:
  fuel_consumption_linear_regression_AUTO.ipynb   EASIEST: the data is built in, no file upload
  fuel_consumption_linear_regression.ipynb        asks you to upload the 3 CSV files below
  trip_records.csv          every trip of Trip Records: date, plate number, distance (km), fuel consumed (L);
                            column source is empty for the GSO's own trips, filled for the online-dataset trips
  vehicle_records.csv       plate number, vehicle model, fuel type, engine power (kW)
  supplementary_data.csv    the other online records, same variables: gasoline trips (Fan & Song 2022)
                            + diesel vans (EEA 2024); each online record is used once

EASIEST WAY (AUTO version):
  1. Open https://colab.research.google.com (signed in to your Google account).
  2. File > Upload notebook > Browse > Desktop > gov-fleets > colab >
     fuel_consumption_linear_regression_AUTO.ipynb > Open.
  3. Runtime > Run all. If a warning appears, click "Run anyway".
  4. Wait 1-2 minutes until every cell has a green check mark.
  5. Section 6 shows R2, MAE, RMSE and the 5-fold CV - the same as python model/train_model.py
     gives on the GSO computer.
  6. The last cell downloads linear_regression_pipeline.joblib and metrics_colab.json (allow the
     browser to download multiple files). They record this run. The web app does not take uploaded
     models: its model is trained on the GSO computer with python model/train_model.py, and it
     never retrains by itself.

The AUTO version contains the data from the day it was made (7,589 trips of Trip Records = 93 GSO + 7,496 online,
9 vehicles, 92,402 other online records = 99,991 records + 9 vehicles = 100,000).
To rebuild the four files from the system's current data: python colab/make_colab_files.py
For newer records, rebuild the three CSV files with python colab/make_colab_files.py
and use fuel_consumption_linear_regression.ipynb:
Run all, then Choose Files and select all three CSV files.
