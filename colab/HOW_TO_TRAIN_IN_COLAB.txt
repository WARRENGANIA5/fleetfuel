TRAIN THE MODEL IN GOOGLE COLAB

Files in this folder:
  fuel_consumption_linear_regression_AUTO.ipynb   EASIEST: the data is built in, no file upload
  fuel_consumption_linear_regression.ipynb        asks you to upload the 3 CSV files below
  trip_records.csv          Monthly Report of Official Travel: date, plate number, distance (km), fuel consumed (L)
  vehicle_records.csv       plate number, vehicle model, fuel type, engine power (kW)
  supplementary_data.csv    online data, same variables: gasoline trips (Fan & Song 2022) + diesel vans (EEA 2024)

EASIEST WAY (AUTO version):
  1. Open https://colab.research.google.com (signed in to your Google account).
  2. File > Upload notebook > Browse > Desktop > gov-fleets > colab >
     fuel_consumption_linear_regression_AUTO.ipynb > Open.
  3. Runtime > Run all. If a warning appears, click "Run anyway".
  4. Wait 1-2 minutes until every cell has a green check mark.
  5. Section 6 shows R2, MAE, RMSE and the 5-fold CV - the same as the
     Model Performance page of the web app.
  6. The last cell downloads linear_regression_pipeline.joblib and metrics_colab.json (allow the
     browser to download multiple files). In the web app, open Model Performance >
     Upload Trained Model from Google Colab, choose the two files and click Upload.
     The system then predicts with this model; it never retrains by itself.

The AUTO version contains the data from the day it was made (93 trips, 9 vehicles, 7,260 online records).
For newer records, download the three CSV files again from the web app
(Model Performance > Upload Trained Model from Google Colab) and use fuel_consumption_linear_regression.ipynb:
Run all, then Choose Files and select all three CSV files.
